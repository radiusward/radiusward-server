(authentication {{ .Values.gateway.ports.auth }}/udp, accounting {{ .Values.gateway.ports.acct }}/udp): when a node fails, the NAS retries
through the other gateway and the cluster recognises the retry.

NAS entries match the source address of the packets: keep externalTrafficPolicy Local (or hostNetwork) so the
address is not rewritten. Before production, read docs/operations/kubernetes.md: node sysctls for Aeron, storage
that honours fsync, upgrades.
