Every RADIUS server has its own address. Configure each NAS with two of them as primary and secondary
(authentication {{ .Values.server.ports.auth }}/udp, accounting {{ .Values.server.ports.acct }}/udp): when a node fails, the NAS retries
through the other RADIUS server and the cluster recognises the retry.

NAS entries match the source address of the packets: keep externalTrafficPolicy Local (or hostNetwork) so the
address is not rewritten. Before production, read docs/operations/kubernetes.md: node sysctls for Aeron, storage
that honours fsync, upgrades.
